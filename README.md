Cloud Blueprints for Adabas & Natural

This repository provides cloud reference blueprints for deploying Adabas & Natural workloads on major hyperscalers. Each blueprint includes architecture guidance, deployment scripts, and supporting documentation to accelerate cloud adoption and modernization.

🏗️ Blueprint Models

| Blueprint     | Description                | Typical Use Case                  |
| ------------- | -------------------------- | --------------------------------- |
| **Basic**     | VM-based deployment        | Dev/Test, lift-and-shift          |
| **Resilient** | Multi-AZ high-availability | Production workloads              |
| **Advanced**  | Container/Kubernetes model | Cloud-native + scaling automation |


🎯 Purpose

These blueprints help you:

Standardize Adabas & Natural deployments on AWS and Azure

Accelerate lift-and-shift and modernization efforts

Apply cloud architecture best practices (security, HA, automation)

Use Infrastructure-as-Code to deploy consistent environments
